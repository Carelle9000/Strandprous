⚙️ Configurer la Réservation Google Form
✅ Formulaire déjà configuré — les URLs ont été renseignées par votre administrateur. Vous pouvez les modifier ci-dessous si nécessaire.
📋 Guide de configuration (3 étapes)
1
Crée ton Google Form
Crée un formulaire avec les champs : Nom, Téléphone, WhatsApp, Email, Service, Date, Heure
🔗 Ouvrir Google Forms
2
Lie les réponses à Google Sheets
Dans ton formulaire → onglet Réponses → icône Google Sheets → crée une nouvelle feuille.
📊 Ouvrir Google Sheets
3
Publie la feuille en CSV
Dans Google Sheets → Fichier → Partager → Publier sur le Web → choisir Feuille 1 + format CSV → cliquer Publier → copier le lien.
Le lien que tu envoies à tes clients pour réserver.
Le lien obtenu après "Publier sur le Web → CSV".
